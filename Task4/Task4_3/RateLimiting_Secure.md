# Rate Limiting

| Тип запроса | Лимит (Rate Limit) | Действие при превышении |
| :--- | :--- | :--- |
| **Публичный запрос:** Поиск врачей | **30 запросов в минуту** с одного IP-адреса. | Блокировка запроса с кодом HTTP 429 Too Many Requests |
| **Авторизованный запрос:** Создание записи к врачу | **10 запросов в минуту** на один client_id (из JWT) + до **100 запросов в сутки**. | Блокировка транзакции с кодом HTTP 429. |



# Меры защиты каналов передачи данных

1. **Шифрование TLS 1.3:** Весь трафик шифруется по протоколу TLS 1.3 с поддержкой совершенной прямой секретности (Perfect Forward Secrecy). Слабые шифры и старые протоколы (TLS 1.0, 1.1) полностью отключены.
2. **Защита через WAF:** Перед API Gateway разворачивается Web Application Firewall для автоматической фильтрации сетевых атак, сигнатур OWASP Top 10 и попыток SQL-инъекций.
